# Design system
Navy #102b45 anchors the institution. Gold #d8b76b marks achievement; blue #245f89 indicates academic actions. White cards sit on #f3f6f9. Segoe UI/system sans provides locally available readable UI typography; Georgia italic adds editorial character to the welcome line.
Use shared ButtonLink, Badge, Card, Progress and EmptyState components. Spacing follows 4/8px increments; card radius 14px, buttons 8px. Prefer subtle borders to heavy shadows.
Desktop uses a stable academy sidebar and flexible study content. Mobile uses a compact header and an explicit expandable menu; no miniature sidebar. Support remains prominent.
Semantic headings, landmarks, labels, status text, keyboard focus rings and a skip link are required. Don't encode state with colour alone. Honour reduced motion. Use meaningful empty/loading/error states. Disabled future actions must explain availability; no simulated success.
